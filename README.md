# TCC_Otimizacao_de_Carteira_de_Acoes
Problemas de otimização com restrições de cardinalidade são desafiadores, mas possuem aplicações relevantes, como na otimização de portfólios. Essa aplicação tem o objetivo de encontrar a combinação que minimize o risco dado um retorno alvo, impondo uma restrição que limita o número de ativos, obtendo soluções esparsas.

Os arquivos _.ipynb_ podem ser executados facilmente, pois estão no Google Colab. Eles foram usados no decorrer do trabalho para a construção dos exemplos, comparativos e resultados.

Os demais arquivos que estão nomeados com _html_, _css_, _py_ e _sql_ são os códigos que compõem o desenvolvimento do aplicativo.
